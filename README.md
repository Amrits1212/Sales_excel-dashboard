# 📊 Excel Sales Dashboard

This project features a dynamic Excel dashboard designed to analyze and visualize sales performance across products, regions, and sales representatives.

## 📁 Files Included
- `dashboard.xlsx` – The Excel file with pivot tables and interactive dashboard

## 🔧 Features
- Pivot tables for product and region analysis
- Interactive slicers
- Automated charts

## 🧰 Tools Used
- Microsoft Excel

## 📌 Purpose
To demonstrate data visualization and dashboard building using Excel.
